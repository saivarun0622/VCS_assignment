# Frequently Asked Questions

## What is a repository?

A repository is a place where project files and their version history are stored.

## Do I need to know a programming language to write Markdown?

No. Markdown is a lightweight markup language that uses simple symbols to format text.

## What does GitHub Pages do?

GitHub Pages hosts static website content from a GitHub repository.

## Why are links between pages useful?

Internal links let visitors move between related documentation pages without returning to the repository file list.

## What should I check if the website does not appear?

- Confirm that the repository is public if required for your setup.
- Open **Settings → Pages** and check that the publishing source is the `main` branch and `/docs` folder.
- Confirm that `index.md` is inside the `docs` folder.
- Wait a little after saving changes, then reload the published site.
- Check that internal links use the correct file names.
