# Usage Guide

This page describes a simple workflow for tracking a project with Git.

## 1. Check the repository

```bash
git status
```

This displays the current state of the working directory and staging area.

## 2. Stage your changes

```bash
git add .
```

This stages changed and new files for the next commit. Review the files before committing.

## 3. Save a commit

```bash
git commit -m "Describe your changes"
```

A commit records the staged changes with a message.

## 4. Upload changes to GitHub

```bash
git push
```

This sends local commits to the configured remote repository.
