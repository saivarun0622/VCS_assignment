# Git and GitHub Documentation

Welcome to this documentation website about **Git and GitHub**. It introduces version control, explains a basic workflow, and answers common beginner questions.

## What is version control?

Version control is a system that records changes to files over time. It helps developers review previous versions, collaborate with others, and recover from mistakes.

## What are Git and GitHub?

- **Git** is a distributed version control system used to track changes in files.
- **GitHub** is an online platform for hosting Git repositories and collaborating on projects.
- **GitHub Pages** can publish static websites directly from a repository.

## Example

```bash
git status
git add .
git commit -m "Add project documentation"
git push
```

These commands check the repository status, stage changes, save a commit, and push commits to a remote repository.
