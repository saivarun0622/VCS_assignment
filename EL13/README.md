# Student Management Demo

A small beginner-friendly Python project demonstrating meaningful Git commits and a clean repository structure.

## Project Structure

- `src/` — application logic for storing and listing students.
- `tests/` — simple tests for the application logic.
- `docs/` — additional project documentation.
- `assets/` — images and other static resources used by the project.

## Requirements

- Python 3.9 or newer

## Run the Demo

From the project root, run:

```bash
python src/main.py
```

## Run the Tests

```bash
python -m unittest discover -s tests
```

## Learning Goals

This repository demonstrates a modular folder layout, a Markdown README, and a Git history made of small commits with descriptive messages.
